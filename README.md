# DDD Perth 2026 — Passkeys audience guide

A public, responsive and printer-friendly companion to George Coldham’s talk, **Authentication for humans: why passkeys finally make sense**. The guide follows the 20 V4B slides, with concise audience notes, implementation and recovery checklists, and standards references.

## GitHub Pages

- Repository: `anothergeorgecoldham/ddd-perth-2026`
- Intended address: <https://anothergeorgecoldham.github.io/ddd-perth-2026/>
- The `pages.yml` workflow publishes `public/` on pushes to `main`.
- If GitHub Pages has not been enabled for the repository, choose **Settings → Pages → Build and deployment → GitHub Actions**.

The site is already static HTML and WebP artwork; there is no runtime service or build dependency.
